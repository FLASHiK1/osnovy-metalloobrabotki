Нормирование: основное и штучное время

Добавьте переходы обработки детали и введите режимы резания. Калькулятор посчитает основное время каждого перехода с учётом врезания и перебега. Затем он сложит штучное время с вспомогательным и подготовительно-заключительным и покажет, сколько деталей выйдет за смену.

Укрупнённое техническое нормирование
Tшт = (To + Tв)·(1 + (αобс + αотд)/100)

Переходы

Время в минутах
Tв — установка и снятие детали, подвод инструмента, смена инструмента, измерения. На токарном станке с ЧПУ для детали средней сложности это обычно 0,5–2 мин. На универсальном — больше. αобс + αотд обычно 8–12 %.
Проверьте поля, выделенные красным.
Штучно-калькуляционное время
—
Как считается
n = 1000·v / (π·D) — обороты по скорости резания To = (l + l₁ + l₂) · i / (n · s) — точение, сверление, резьба (s — подача или шаг, мм/об) To = (l + l₁ + l₂) · i / Sм, Sм = fz · z · n — фрезерование Tшт = (ΣTo + Tв) · (1 + (αобс + αотд)/100) Tшк = Tшт + Tп-з / N

Врезание l₁ и перебег l₂:

  • точение — t/tg φ + 1…2 мм на подвод и 1…3 мм перебега (у упора — без перебега);
  • сверление — 0,3·D (заборный конус 118°) плюс 1…2 мм, для сквозного отверстия ещё 1…3 мм выхода;
  • торцевое фрезерование симметричное — 0,5·(D − √(D² − B²)) + 1…3 мм, на выход — половина диаметра фрезы, если надо пройти всю поверхность;
  • фрезерование концевой фрезой сбоку — √(B·(D − B)) + 1…3 мм;
  • резьба — 2…3 шага на подвод. Метчик выкручивается, поэтому время удваивается при одинаковых оборотах.

При торцевании с постоянными оборотами расчёт ведётся по наибольшему диаметру. На ЧПУ с постоянной скоростью резания (G96) обороты растут к центру, и время меньше.

Укрупнённый расчёт. Для заводских норм используйте отраслевые нормативы вспомогательного времени.
