Сборка с натягом

Выберите посадку и материалы. Калькулятор скажет, до какой температуры нагреть ступицу или охладить вал, чтобы детали собрались свободно, и посчитает, какой момент выдержит соединение.

формулы Ляме
ГОСТ 25347 (посадки)
Смятие неровностей ≈ 1,2·(Rz вала + Rz отверстия): при Ra 0,8 и 1,6 — около 11 мкм. Трение: 0,08–0,10 при запрессовке со смазкой, 0,12–0,18 при тепловой сборке.

Прочность соединения

при наименьшем натяге — гарантированно, при наибольшем — по прочности деталей
Как считается

Температура нагрева — чтобы отверстие увеличилось на наибольший натяг плюс зазор для свободной сборки:

ΔT = (Nmax + Sсб) / (α · d), T = 20 °C + ΔT

Давление на поверхности контакта по формулам Ляме для толстостенных цилиндров:

p = (N − u) / (d · (C₁/E₁ + C₂/E₂)) C₁ = (1 + (d₁/d)²) / (1 − (d₁/d)²) − ν₁ вал C₂ = (1 + (d/D₂)²) / (1 − (d/D₂)²) + ν₂ ступица момент T = p · π · d² · L · f / 2 усилие F = p · π · d · L · f

u — поправка на смятие микронеровностей, она уменьшает действующий натяг. Эквивалентное напряжение на внутренней поверхности ступицы: σ = 2·p / (1 − (d/D₂)²) — его сравнивают с пределом текучести.

Коэффициенты линейного расширения при охлаждении меньше, чем при нагреве, поэтому для азота и сухого льда взяты средние значения на этом интервале температур.

Инженерная оценка. Для ответственных соединений учитывайте центробежные силы, рабочую температуру и разброс натяга по ГОСТ 25347.
