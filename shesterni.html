Зубчатые колёса

Введите модуль и числа зубьев — калькулятор посчитает размеры обоих колёс, межосевое расстояние и длину общей нормали для контроля. Ниже — как узнать модуль у готовой шестерни.

ГОСТ 16532-70, ГОСТ 9563-60
исходный контур ГОСТ 13755-2015

Узнать модуль у готовой шестерни

прямозубая, без смещения
Как считается
торцовый модуль mt = m / cos β делительный d = mt · z вершин da = d + 2·m впадин df = d − 2,5·m основной db = d · cos αt, tg αt = tg α / cos β межосевое a = (d₁ + d₂) / 2 шаг p = π · m, высота зуба h = 2,25·m

Длина общей нормали (для прямозубых) — размер, который меряют микрометром с тарельчатыми губками через несколько зубьев: W = m · cos α · [π·(zw − 0,5) + z · inv α], где zw — число охватываемых зубьев, inv α = tg α − α.

Коэффициент торцового перекрытия εα показывает, сколько пар зубьев в среднем одновременно в зацеплении; для плавной работы нужно не меньше 1,2. Меньше 17 зубьев у прямозубого колеса без смещения — подрезание ножки зуба.

Модуль по шестерне: m = da / (z + 2). Для дюймовых колёс задают Diametral Pitch: m = 25,4 / DP.

Геометрия без смещения исходного контура. Для колёс со смещением, внутреннего зацепления и прочностного расчёта нужен расчёт по ГОСТ 16532 и ГОСТ 21354.
