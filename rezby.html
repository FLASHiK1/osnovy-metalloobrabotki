Где ставить на чертеже
  • Деталь с наружной резьбой — на размерной линии наружного диаметра, обозначение пишется над ней вместо «⌀»: M12-6g. Длину резьбы — отдельным размером, без сбега.
  • Деталь с внутренней резьбой — на выносной полке или размерной линии по наружному диаметру резьбы (сплошная тонкая линия на виде): M12-6H. Глубину резьбы и глубину сверления под неё — отдельными размерами.
  • Сборочный чертёж — допуск соединения дробью 6H/6g, если он важен для сборки; для стандартного крепежа обычно не указывают, он задан стандартом на крепёж.
  • Технические требования — общие указания: «Резьба по ГОСТ 24705, поле допуска 6g», «Размеры резьбы до покрытия», «Неуказанные фаски на резьбе 1×45°».

S — короткая, N — нормальная, L — длинная длина свинчивания. Самое ходовое сочетание — 6H/6g. В скобках — поля второго ряда. Буквы основного отклонения: h — без зазора, g — небольшой зазор (общий случай), f и e — зазор под толстое покрытие или работу при нагреве.

Крепёж: отверстия и размер под ключ

для резьб с крупным шагом M3–M48

Отверстия под крепёж — ГОСТ 11284-75 (ISO 273): ряд 1 — точный, 2 — средний, 3 — грубый. Размер под ключ — ISO 4032; в скобках старый размер по ГОСТ 5915-70, который ещё встречается.

Трубная цилиндрическая резьба G

ГОСТ 6357-81, ISO 228-1

Обозначение «G1/2» — условный размер трубы в дюймах, а не диаметр резьбы. Наружный диаметр резьбы G1/2 — 20,955 мм.

Как считается

Профиль метрической резьбы — равносторонний треугольник со срезанными вершинами, угол 60°. Основные диаметры по ГОСТ 24705:

d₂ = d − 0,6495·P средний диаметр d₁ = d − 1,0825·P внутренний диаметр (гайки) d₃ = d − 1,2269·P внутренний диаметр болта по дну впадины H = 0,8660·P высота исходного треугольника

Поле допуска болта «6g»: 6 — степень точности, g — основное отклонение (зазор под покрытие или смазку). У болта нормируются наружный диаметр d и средний d₂, у гайки — средний D₂ и внутренний D₁. Допуски берутся по ГОСТ 16093 (ISO 965-1); для других степеней точности допуск 6-й степени умножается на 0,63 (4), 0,8 (5), 1,25 (7) или 1,6 (8) с округлением по ряду R40.

Для мелких шагов допуск среднего диаметра считается по формуле ISO 965-1: Td₂(6) = 90·P0,4·d0,1 мкм с округлением по ряду R40. Результат может отличаться от таблицы стандарта на одну ступень ряда — для приёмки сверяйте с ГОСТ 16093.

Сверло под нарезной метчик ≈ D − P. Для раскатника (метчика без стружки) отверстие больше: примерно d − 0,45·P — точное значение берите из каталога метчика.

Значения рассчитаны по ГОСТ 24705, 8724, 16093. Для приёмки ответственных деталей сверяйте со стандартом.
