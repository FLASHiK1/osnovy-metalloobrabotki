# Основы металлообработки

Бесплатные инженерные калькуляторы по металлообработке: посадки и допуски, размерные цепи, шероховатость, режимы резания, резьбы, масса металла, аналоги марок сталей, конусы, гибка листа, расход на сварку. По ГОСТ, ISO, GB и старым ОСТ.

Сайт: https://flashik1.github.io/osnovy-metalloobrabotki/

Каждая страница — самостоятельный HTML-файл без сборки и серверной части.

| Файл | Калькулятор |
|---|---|
| index.html | Главная |
| posadki.html | Посадки и допуски |
| razmernye-cepi.html | Размерные цепи |
| sherokhovatost.html | Шероховатость |
| rezhimy-rezaniya.html | Режимы резания |
| rezby.html | Метрическая резьба |
| konusy.html | Конусы |
| gibka-lista.html | Гибка листа |
| raskroy-lista.html | Раскрой листа |
| rashod-elektrodov.html | Расход электродов и проволоки |
| dyuymy.html | Дюймы и дюймовые резьбы |
| sebestoimost.html | Себестоимость детали |
| massa-metalla.html | Масса металла |
| analogi-staley.html | Аналоги сталей и сплавов |

Счётчик Яндекс Метрики вставляется в `<head>` каждой страницы на место комментария.

## Устройство

- `assets/site.js`, `assets/site.css` — общая обвязка всех страниц: верхнее меню, «Поделиться расчётом» (состояние калькулятора кодируется в ссылке `?s=…`), печать в PDF, регистрация офлайн-режима.
- `assets/early.js` — до загрузки калькулятора подставляет расчёт из присланной ссылки.
- `sw.js`, `manifest.webmanifest` — офлайн-режим и установка на телефон. **После изменения файлов сайта увеличьте `VERSION` в `sw.js`**, иначе у вернувшихся посетителей останется старая версия общих файлов.
- `src/parts/*.html` + `src/base.css` — исходники калькуляторов; сборка: `python3 src/build.py` (собирает страницы и запускает `src/inject.py`).
- `posadki.html`, `razmernye-cepi.html`, `rezhimy-rezaniya.html`, `index.html` правятся прямо в корне; после правки запустите `python3 src/inject.py`.
