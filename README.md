# Основы металлообработки

Бесплатные инженерные калькуляторы по металлообработке: посадки и допуски, размерные цепи, шероховатость, режимы резания, резьбы, масса металла, аналоги марок сталей. По ГОСТ, ISO, GB и старым ОСТ.

Сайт: https://flashik1.github.io/osnovy-metalloobrabotki/

Каждая страница — самостоятельный HTML-файл без сборки и серверной части.

| Файл | Калькулятор |
|---|---|
| index.html | Главная |
| posadki.html | Посадки и допуски |
| razmernye-cepi.html | Размерные цепи |
| sherokhovatost.html | Шероховатость |
| rezhimy-rezaniya.html | Режимы резания |
| rezby.html | Метрическая резьба |
| massa-metalla.html | Масса металла |
| analogi-staley.html | Аналоги сталей и сплавов |

Счётчик Яндекс Метрики вставляется в `<head>` каждой страницы на место комментария.
