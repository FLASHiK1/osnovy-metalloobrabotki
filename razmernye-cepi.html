Как считается

Увеличивающие звенья (→) при увеличении увеличивают замыкающее звено, уменьшающие (←) — уменьшают. ES и EI — верхнее и нижнее отклонения, T = ES − EI, Ec = (ES + EI)/2 — координата середины поля.

Максимум-минимум гарантирует полную взаимозаменяемость:

A_Δ = ΣA_ув − ΣA_ум ES_Δ = ΣES_ув − ΣEI_ум EI_Δ = ΣEI_ув − ΣES_ум T_Δ = ΣT_i

Вероятностный метод допускает малый процент риска выхода за пределы:

E_cΔ = ΣE_c,ув − ΣE_c,ум T_Δ = t · √(Σ λ_i² · T_i²) ES_Δ = E_cΔ + T_Δ/2, EI_Δ = E_cΔ − T_Δ/2

Коэффициент риска t: 3,29 при 0,1 %, 3,0 при 0,27 %, 2,57 при 1 %, 2,0 при 4,5 %, 1,65 при 10 %. Коэффициент λ²: 1/9 для нормального закона, 1/6 для закона Симпсона, 1/3 для равновероятного.

Монте-Карло разыгрывает 100 000 сборок: каждое звено случайно в своём поле допуска по выбранному закону. Нормальный закон — с центром в середине поля и σ = T/6.

Подбор квалитета: единица допуска i = 0,45·∛D + 0,001·D мкм, где D — среднее геометрическое интервала размеров. Среднее число единиц a = T_Δ / Σi (максимум-минимум) или a = T_Δ / (t·√Σλ²i²) (вероятностный). Выбирается ближайший квалитет с числом единиц не больше a: IT5 — 7, IT6 — 10, IT7 — 16, IT8 — 25, IT9 — 40, IT10 — 64, IT11 — 100, IT12 — 160, IT13 — 250, IT14 — 400.

Поля допусков: валы d, e, f, g, h, js, k, m, n, p и отверстия D, E, F, G, H, JS, K, M, N, P, квалитеты 5–14, размеры до 500 мм. Для остальных полей введите отклонения числами.

Значения отклонений рассчитаны по таблицам ГОСТ 25346/25347 (ISO 286). Для ответственных узлов сверяйте результат со стандартом.
