Расчёт вала на кручение и изгиб

Минимальный диаметр вала по мощности и оборотам или по моменту. Если на вал действует изгиб от шестерни, шкива или звёздочки, введите изгибающий момент: диаметр посчитается по эквивалентному моменту. Ниже проверка выбранного диаметра на прочность и жёсткость.

Проектный расчёт валов
Ряд диаметров — ГОСТ 6636 (Ra40)
[τ] здесь — пониженное допускаемое напряжение для проектного расчёта: оно с запасом учитывает изгиб, концентраторы и усталость, которые пока неизвестны. Обычно берут 15–30 МПа для выходных концов валов и 10–15 МПа для входных валов редукторов.
Проверьте поля, выделенные красным: нужны положительные числа.
Рекомендуемый диаметр (ГОСТ 6636)
—
Как считается
T = 9550 · P / n — момент, Н·м (P в кВт, n в об/мин) d ≥ ∛(16 · T / (π · [τ])) — по кручению Mэкв = √(M² + 0,75 · T²) — эквивалентный момент (IV теория прочности) d ≥ ∛(32 · Mэкв / (π · [σ]и)) — по совместному действию изгиба и кручения τ = 16·T/(π·d³), σ = 32·M/(π·d³), σэкв = √(σ² + 3τ²) φ = T · L / (G · Ip), Ip = π·d⁴/32, G = 80 000 МПа

Это проектный расчёт: по нему выбирают диаметры ступеней. Для окончательной проверки ответственного вала выполняют уточнённый расчёт на выносливость: с коэффициентами концентрации напряжений у шпоночных пазов, галтелей и посадок с натягом, масштабным фактором и запасом прочности по усталости s ≥ 1,5…2,5.

Подсказки допускаемых напряжений — ориентировочные значения из учебной литературы по деталям машин. Для изгиба [σ]и около 50–60 МПа для стали 45 и 70–80 МПа для улучшенной 40Х соответствуют симметричному циклу с запасом.

Угол закручивания для валов общего назначения ограничивают 0,5–1 ° на метр длины, для точных передач и ходовых винтов — 0,25 °/м.

Проектная оценка. Ответственные валы проверяйте на выносливость с учётом концентраторов напряжений.
