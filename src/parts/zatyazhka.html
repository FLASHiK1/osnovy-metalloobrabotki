Момент затяжки болтов

Выберите резьбу, класс прочности и состояние поверхности. Калькулятор посчитает усилие затяжки и момент для динамометрического ключа с учётом трения в резьбе и под головкой.

VDI 2230, ISO 898-1
ISO 3506 (нержавеющие)
90 % — стандартное значение VDI 2230 для затяжки до допустимого эквивалентного напряжения. Для соединений, которые часто разбирают, или при неточном ключе берите 70–80 %.
Момент затяжки
—
Момент очень чувствителен к трению: при μ 0,10 вместо 0,14 тот же момент даёт почти на 30 % большее усилие и может сорвать резьбу. Берите μ по фактическому состоянию болта, а не «как обычно».

Моменты для всех размеров

Как считается

Допустимое усилие затяжки — такое, при котором эквивалентное напряжение в стержне (растяжение плюс кручение от трения в резьбе) равно заданной доле ν предела текучести Rp0,2:

Fм = ν · Rp0,2 · As / √(1 + 3·[1,5 · (d₂/d₀) · (P/(π·d₂) + 1,155·μ)]²) As = π/4 · d₀², d₀ = (d₂ + d₃)/2 — площадь сечения по резьбе Mз = Fм · (0,16·P + 0,58·μ·d₂ + μ·Dкм/2) Dкм = (Dголовки + Dотверстия)/2 — средний диаметр опоры

Первое слагаемое момента — работа на шаг резьбы, второе — трение в резьбе, третье — трение под головкой. Обычно на трение уходит 85–90 % момента, и лишь 10–15 % создаёт усилие.

Пределы текучести по ISO 898-1: 4.6 — 240 МПа, 5.6 — 300, 5.8 — 400, 6.8 — 480, 8.8 — 640 (до M16) и 660 (свыше), 10.9 — 940, 12.9 — 1100; по ISO 3506: A2-70 — 450, A4-80 — 600 МПа. Отверстие под болт — средний ряд по ГОСТ 11284.

Динамометрический ключ имеет разброс: стрелочный и щелчковый ±20–25 %. Поэтому в ответственных соединениях затягивают по углу поворота или контролируют удлинение болта.

Расчётный момент для стальных деталей. Для алюминиевых корпусов, мягких прокладок и коротких резьб в отверстиях проверьте смятие и срез витков отдельно.
