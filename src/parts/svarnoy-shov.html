Прочность сварного шва

Выберите тип соединения, введите нагрузку и размеры шва. Калькулятор посчитает напряжения в шве и сравнит их с допускаемыми для выбранного способа сварки, а для угловых швов найдёт потребный катет.

Угловой шов разрушается по биссектрисе — сечению высотой 0,7·k (для ручной сварки). Катет не делают меньше 3 мм и больше 1,2 толщины тонкой детали. Фланговые швы длиннее 60·k работают неравномерно, их расчётную длину ограничивают.

В длину шва не включают кратеры на концах: при сварке без выводных планок из фактической длины вычитают примерно по k с каждого конца.
