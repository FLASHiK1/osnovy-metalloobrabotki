Как считается

Отклонения берутся по таблицам ГОСТ 25346/25347 (ISO 286): допуск квалитета IT и основное отклонение поля. Для отверстий K, M, N (до IT8) и P, R, S (до IT7) применяется поправка Δ = ITn − ITn−1.

S_max = ES − ei S_min = EI − es N_max = es − EI N_min = ei − ES T_посадки = TD + Td

Для переходной посадки вероятность зазора и натяга считается при нормальном распределении размеров отверстия и вала с центром в середине поля и σ = T/6. Тогда σ посадки = √(TD² + Td²)/6.

Подбор перебирает поля в системе отверстия (H5–H11) и вала (h5–h11) с валами и отверстиями c…s, квалитет отверстия равен квалитету вала или грубее на один. Подходят посадки, у которых все возможные зазоры лежат внутри заданных пределов. Сначала показаны часто применяемые посадки, затем — с наибольшим допуском посадки, они дешевле в изготовлении.

Поддерживаются поля c, d, e, f, g, h, js, k, m, n, p, r, s (валы) и C…S (отверстия), квалитеты 5–18, размеры до 500 мм.

Стандарты. Значения ГОСТ 25346/25347 совпадают с ISO 286-1/-2, китайским GB/T 1800.1/.2, немецким DIN EN ISO 286, американским ANSI B4.2 (метрические посадки) и японским JIS B 0401. Поэтому поле H7 по любому из них даёт те же отклонения.

Старая система ОСТ (до перехода на ЕСДП в 1980-х) переводится в ЕСДП по справочным таблицам замены: А → H7, А1 → H6, А3 → H8 (или H9), С → h6, Д → g6, Х → f7, Х1 → f6, Л → e8, Ш → d8, П → js6, Н → k6, Т → m6, Г → n6, Пр → r6 (или s6), С3 → h8, Х3 → f9 (или e9). Замена считается допустимой, если отклонения ЕСДП выходят за поле ОСТ не более чем на 10 %. Для ответственных деталей сверяйте с исходной таблицей ОСТ.

Отраслевые стандарты (например, ОСТ 1 00022 для авиации) пока не включены: их таблицы нужно взять из официального текста стандарта.

Значения рассчитаны по таблицам ГОСТ 25346/25347. Для ответственных узлов сверяйте результат со стандартом.
